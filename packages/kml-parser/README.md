# kml-parser

Parses a Google Earth KML file into the unified `hole.json` schema used by the rest of the SG engine.

## Install

```bash
uv sync  # from repo root
```

## CLI

```bash
python -m kml_parser parse path/to/hole.kml --out data/holes/hole15.json
```

Prints a summary (hole number, par, UTM zone, tee→cup distance, zone counts, tree count, total polygon area) and writes the JSON.

## KML conventions

Every relevant feature is a `<Placemark>` with `<ExtendedData>` describing what it represents. In Google Earth Pro, edit a placemark → Advanced → Add → Data, and set the keys below.

### Required global

Exactly one `tee` and one `cup` point per file (or one per hole, if a file contains multiple holes — then disambiguate with `hole_number`).

### Tee (point)

| key           | required | example | notes |
|---------------|----------|---------|-------|
| `zone`        | yes      | `tee`   |       |
| `hole_number` | yes      | `15`    | int   |
| `par`         | no       | `4`     | default 4 |

### Cup (point)

| key           | required | example | notes |
|---------------|----------|---------|-------|
| `zone`        | yes      | `cup`   |       |
| `hole_number` | yes      | `15`    | int   |

### Polygon zones

`zone` ∈ `tee | fairway | first_cut | rough | deep_rough | green | fringe | sand | water | oob`

| key               | required | example | notes |
|-------------------|----------|---------|-------|
| `zone`            | yes      | `fairway` | |
| `firmness`        | no       | `0.85`   | 0..1, default 0.7 |
| `rough_length_in` | no       | `2.5`    | inches; only meaningful for rough zones |

### Trees (point)

| key         | required | example | notes |
|-------------|----------|---------|-------|
| `zone`      | yes      | `tree`  |       |
| `radius_ft` | no       | `6`     | default 6.0 |
| `height_ft` | no       | `50`    | default 50.0 |
| `density`   | no       | `0.5`   | tree-hit prob per yard, default 0.5 |

### Target line (LineString)

A single LineString placemark with `zone=target_line` representing the strategic line from tee through the middle of the green. Optional; defaults to a straight segment from tee to cup.

## Output schema

See `PLAN.md` and `src/kml_parser/schema.py`. All coordinates are local-frame meters; absolute UTM = local + `utm_origin_m`.
